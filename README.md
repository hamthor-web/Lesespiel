# Interaktive Fußballgeschichten

Dieses Paket enthält die fertige statische Web-App für GitHub Pages.

## Auf GitHub veröffentlichen

1. Ein neues GitHub-Repository anlegen.
2. Den **Inhalt dieses Ordners** hochladen: `index.html`, `assets`, `.nojekyll` und `README.md`.
3. Im Repository **Settings → Pages** öffnen.
4. Unter **Build and deployment** die Option **Deploy from a branch** wählen.
5. Als Branch **main** und als Ordner **/(root)** auswählen und speichern.

Nach kurzer Zeit zeigt GitHub dort die Adresse der veröffentlichten App an.

Die App benötigt keinen Server und keine Datenbank. Der Lesefortschritt wird ausschließlich im Browser des verwendeten Geräts gespeichert.
